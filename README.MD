# Elbilar och klimatet

Det här är vårt webbprojekt om elbilar och klimatpåverkan.

Vi jämför elbilar med bensin- och dieselbilar och tittar på kostnad, förbrukning och klimatpåverkan.

## Syfte 

Syftet är att göra det enklare att förstå skillnaderna mellan elbilar och fossilbilar.

Vi vill bland annat visa:

- skillnader i kostnad
- skillnader i bränsleförbrukning
- skillnader i klimatpåverkan
- varför det kan vara svårt att jämföra olika typer av bilar

## Webbplatsens sidor

Webbplatsen består av sex HTML-sidor:

1. `index.html` – Startsida
2. `subject-area.html` – Ämnesområde
3. `challenge.html` – Utmaning
4. `idea.html` – Idé
5. `hypothesis.html` – Hypotes
6. `references.html` – Referenser

## Teknik

Vi har använt:

- HTML5 för struktur och innehåll
- CSS för design och layout
- Media queries för att anpassa sidan till olika skärmstorlekar

## Vårt ämne

**Ämnesområde:** Elbilar och klimatpåverkan

**Core concept:** Klimatpåverkan och bränsleförbrukning.

**Impact:** Elbilar kan vara ett alternativ till bensin- och dieselbilar och kan påverka både bränsleförbrukning och klimatpåverkan.

**Utmaning:** Det kan vara svårt för kunder att förstå skillnaderna mellan elbilar och fossilbilar när det gäller kostnad, bränsleförbrukning och klimatpåverkan.

**Idé:** Att göra jämförelsen enklare genom tydligare information om olika typer av bilar.

**Hypotes:** Om kunder får enkel och tydlig information kan de få bättre förutsättningar att jämföra elbilar och fossilbilar.
